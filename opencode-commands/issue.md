description: Get going with an issue

Lets solve issue $ARGUMENTS!

- fetch the issue via "gh issue ... --json" and understand it
- if you detect any ambiguities, prompt the user
- when all ambiguities are resolved, please
  - update the issue description with the new, clarified content.
  - comment on the issue with any TODO list or implementation plan you came up with
- Now that the github issue reflects our understanding and plans: please implement!
- when done, do NOT commit yet!
